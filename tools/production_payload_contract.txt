# STEMwerk 2.3.1.0 authoritative production payload contract.
#
# The set of repo-relative files required for a correctly installed
# production copy of STEMwerk, independent of any single distribution
# route (ReaPack/index.xml, deb, rpm, Arch, macOS, Windows).
#
# Format: one entry per line, <platform><TAB><repo-relative-path>.
# platform is one of: common, linux, macos, windows.
# "common" entries are required on every platform; platform-tagged
# entries are required only for that platform's native install AND for
# ReaPack (which serves all platforms from one shared catalog).
#
# This is release-engineering source-of-truth data, not generated from
# and not copied from any single existing distribution manifest. It was
# built from independent evidence: released entrypoints, Setup/Repair
# code paths, actual runtime dofile/import/subprocess call sites, and
# existing native build tooling -- see
# tools/release_gate.py:check_production_payload_contract() for how
# it is consumed, and the 2.3.1.0 release-prep evidence archive for
# the full audit trail.
#
# Source-code reachability scanning (tools/release_gate.py's static
# dofile/loadfile scan and its small dynamic-dispatch declaration)
# remains useful as defense-in-depth and a drift signal, but this file
# is the normative list every distribution route is checked against.
#
# Deliberately excluded (not production-required): tests, benchmarks,
# dev-only debug-toggle/manual-fallback scripts, CI/i18n-validation
# tooling, release/build scripts themselves, docs not read at runtime,
# and packaging metadata (pyproject.toml) not imported by any runtime
# code. See the classification evidence archive for the full reasoning
# per excluded file.
#
# Update this file, with evidence, whenever a new file becomes part of
# a supported release flow.
