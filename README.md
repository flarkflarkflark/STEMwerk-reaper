# THEMEwerk-reaper

A fast, local-first theme browser for REAPER.

## v0.1 Features
- Local `ColorThemes` scanning.
- Real-time search/filtering.
- Keyboard navigation (Arrows/Enter).
- Revert to previous theme logic.
- Persistence for Favorites and Recents via ExtState.

## Usage
1. Load `scripts/THEMEwerk.lua` in REAPER.
2. Type to filter themes.
3. Use Arrow Keys to navigate, Enter to apply.
