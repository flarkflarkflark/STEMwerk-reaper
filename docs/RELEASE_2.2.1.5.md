## STEMwerk v2.2.1.5

This hotfix improves REAPER workflow reliability and adds a few requested quality-of-life options.

### Fixed

- waveform peaks now build immediately after imported/replaced stems
- reduced UI lag when no item is selected
- improved time-selection target detection for muted / solo-filtered items and tracks
- improved in-place replacement behavior for partial item overlaps

### Added

- configurable stem file destination: `Temp`, `Project`, or `Custom`
- configurable track/item color handling
- small Windows offline patch installer for existing installer-based setups

### Windows

Release assets now include:

- `STEMwerk-Setup-2.2.1.5.exe`
- `STEMwerk-Setup-2.2.1.5-bundled.exe`
- `STEMwerk-2.2.1.5-offline-patch.exe`
